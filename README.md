# 💰 Expense Tracker

A full-stack Expense Tracker application built using React, Node.js, Express.js, and MongoDB.

## Features

- Add income and expense transactions
- View recent transactions
- Delete transactions
- Calculate total balance, income, and expenses
- Store transactions in MongoDB Atlas
- Responsive dashboard UI

## Tech Stack

**Frontend**
- React.js
- Vite
- CSS

**Backend**
- Node.js
- Express.js
- Mongoose

**Database**
- MongoDB Atlas

## Project Structure

- `frontend/` — React user interface
- `backend/` — Express API and MongoDB integration
