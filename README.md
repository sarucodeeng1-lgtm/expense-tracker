# Expense Tracker

🚀 [Live Demo](https://expense-tracker-y3vg.onrender.com)

A full-stack Expense Tracker built using React, Node.js, Express, and MongoDB.
## Features
- Add and manage transactions
- Track income and expenses
- Calculate total balance
- Store transaction data in MongoDB

## Tech Stack
React.js | Node.js | Express.js | MongoDB Atlas
